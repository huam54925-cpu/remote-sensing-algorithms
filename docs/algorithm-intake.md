# 算法与数据接收清单

每个算法应交付：名称/版本/公式及变量含义；源码来源/版本/许可证；依赖和系统库版本；一条可运行命令；输入测试影像与波段顺序/分辨率/反射率单位/缩放/nodata/CRS；参数默认值/边界；独立参考输出及容差。

真实影像需保留卫星、产品 ID、时间、范围、授权来源、原始与预处理文件哈希、裁剪/重采样/云掩膜方法、可复现获取脚本。下载与预处理在容器外完成，批处理容器读取离线数据。小数组仅用于边界测试。

接入流程：先完成单个算法本机运行和参考值比对，再登记到统一入口，锁定依赖，在只读根文件系统的容器中用真实数据测试，最后扩展其他算法。当前尚未选择首个算法、基础镜像和最终目标平台。
